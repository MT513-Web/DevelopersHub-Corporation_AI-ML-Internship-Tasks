# Customer Churn Prediction ML Pipeline

## Project Overview
This project builds an end-to-end machine learning pipeline for predicting customer churn using the Scikit-learn Pipeline API.

The workflow includes:
- Data preprocessing
- Feature scaling & encoding
- Model training
- Hyperparameter tuning
- Model evaluation
- Model export using joblib

---

## Dataset
- Telco Customer Churn Dataset

---

## Technologies Used
- Python
- pandas
- numpy
- scikit-learn
- joblib

---

## Models Implemented
- Logistic Regression
- Random Forest Classifier

---

## Key Features
- Preprocessing using `Pipeline` and `ColumnTransformer`
- Scaling with `StandardScaler`
- Encoding with `OneHotEncoder`
- Hyperparameter tuning using `GridSearchCV`
- Evaluation using Accuracy Score & Classification Report
- Exported trained pipeline as `.pkl` file

---

## Final Outcome
Successfully developed a reusable and production-ready ML pipeline for customer churn prediction.
